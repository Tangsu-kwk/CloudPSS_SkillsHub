# CloudPSS 短路辅助建模

使用随包 SDK，在会话工作区维护一份可恢复的模型副本。每次查询或编辑调用本 Skill 的 `scripts/workspace.py`。执行器可以在每轮重启，沿用同一个工作区路径即可。按[工作区调用说明](references/workspace.md)准备运行环境。

- 首次读取用户指定的源 RID 或本地模型。后续从工作区读取当前版本。工作区不可用时，说明未能恢复的改动，并根据用户意图重新确定起点。
- 先按实例身份和画布定位故障元件，从实际定义确认参数含义及单位。用户要求改变故障持续时间时，核对开始、结束与所选 EMT 时间范围。引用共享变量或条件表达式时，先说明需要解析的字段及作用域。
- 用户要改单相或两相故障时，先核对受影响相别和实际接线。三相故障电阻的 `ft` 选择切换电阻的相别，接地或相间回路需核对两端。选择相别前查元件定义中的枚举，通过改参预览回显本次选择。
- 建立显式连线前，用 `ports` 查实际端口，用 `edges` 查已有连接。按定义核对电气或信号类型、方向、维度和启用条件。通道合并器或分解器要用实际行生成的端口 key。接线后回读两端；删除元件时核对随它移除的边和仍保留的邻接元件。
- 配置电流记录前，核对故障元件实际输出的信号、维度、所选参数方案和 EMT 方案。复用记录通道时，核对同画布上的输入绑定，并确认记录器 ID 列入选定方案的输出。涉及更换既有信号名时，先检查其消费者。
- 将拟修改内容生成预览。取得用户对该预览的确认后执行，回读工作副本。若工作版本已变化，重新基于实际版本生成预览。
- 用户只要求准备模型时，交付改动、当前版本及量测绑定。删除元件前核对关联边和方案中对该元件的引用。用户要求计算时，导出工作模型和交接文件，将交接文件交给短路分析 Skill 的工作副本入口。
- 用户要求留档时，对当前最终版本生成另存预览并确认，只创建新 RID。根据回执报告是否保存，以及图元、连线、参数方案和计算方案是否回读一致。结果不明时先核对目标 RID。
