# 分层验收

每条证据记录场景、输入、工具入口、请求、返回、失败阶段与回读快照；认证字段脱敏。

| 层级 | 需要的证据 | 不能推出 |
|---|---|---|
| 离线运行时 | SDK对象/FakeModel及模拟云端边界下的 CRUD、预览、错误处理检查 | 真实云端可用或自然语言可用 |
| 宿主适配 | 自动发现、DynamicSkillExecutor、会话复用、分页和实际运行时执行 | LLM会选择正确工具 |
| 真实对话 | 实际 LLM和自动挂载 Skill，根据普通用户需求选择工具；保留消息和事件 | 云端/仿真通过（若使用离线模型） |
| 真实结构 | 可访问 CloudPSS模型内存修改及回读 | 拓扑或仿真正确 |
| 真实拓扑 | 当前修改版本临时 revision创建、拓扑刷新 | 云端模型已保存或物理正确 |
| 云端保存 | create新 RID及云端结构回读一致 | 仿真正确 |
| 仿真 | 由其他 Skill完成新 RID编译、初始化、运行及结果对比 | 本 Skill已覆盖所有元件组合 |

逐模板“通过”必须附覆盖范围：新增、哪些参数、哪些 pins、删除、非法输入；选定字段测试不等于所有字段和全部组合。

编辑失败区分预览校验失败、确认失效、执行失败、回读失败、拓扑失败。串行批量需记录已成功项和未执行项。拓扑失败不隐瞒已经提交的内存编辑。

保存使用 api-contracts.md 中的四种状态，超时不自动重试。仿真与报告由对应 Skill单独记录，不作为辅助建模运行时内部步骤。
