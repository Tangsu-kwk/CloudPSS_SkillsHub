# 数据来源与优先级

## 来源映射

按证据角色而非单纯按文件扩展名分类。

| 角色 | 常见文件 | 用途 |
| --- | --- | --- |
| 用户上下文 | 对话、需求说明 | 目标、读者、范围、语言、风格、输出路径 |
| CloudPSS 导出索引 | `simulation-results/<RID>/manifest.json` | 结果 RID、仿真类型、文件清单、图组标题和通道映射 |
| 主报告 | `.md`、`.html`、`.txt`、确认的报告文档 | 展示事实、既有结论、名称、窗口、面向读者的术语 |
| 结构化元数据 | `.json`、`.yaml`、`.xml` | 溯源、配置、标识符、字段结构 |
| 结果表 | `.csv`、`.xlsx`、`.tsv` | 详细数值表与比较 |
| 原始时间序列 | 单通道 CSV、测量导出 | 图表、采样/时间范围、数据现象 |
| 模型/配置 | 模型导出、参数文件 | 仅在相关时补充背景 |

## CloudPSS 结果导出

收到结果 RID 时，先从当前用户工作区运行 `scripts/export-simulation-result.py`。脚本固定输出到 `simulation-results/<RID>/`：

- `manifest.json` 是唯一入口，所有数据文件按其中的相对路径定位。
- 潮流结果输出 `buses.csv` 和 `branches.csv`，作为结果表。
- 电磁暂态结果按图组输出 `plot_000.csv` 等文件，作为原始时间序列。
- Token 是必填输入。执行脚本前，Agent 在命令中显式引用 `CLOUDPSS_LOGIN_TOKEN` 和 `CLOUDPSS_TOKEN`，优先取 `CLOUDPSS_LOGIN_TOKEN`，为空时取 `CLOUDPSS_TOKEN`，并作为 `--token` 参数传入；脚本不读取环境变量。
- 两个候选变量均为空时停止导出，并提示“当前运行环境缺少 CloudPSS Token，无法导出仿真结果。”；Token 不得写入索引、CSV、报告或日志。
- 不要扫描或引用 `manifest.json` 未列出的同目录旧文件。

## 优先级

1. 用用户上下文确定报告目的和表达方式。
2. 用主报告确定展示事实和报告文字基准。
3. 用 `manifest.json` 和其他结构化元数据补足缺失的结构或溯源信息。
4. 用结果表展示详细数值。
5. 用原始时间序列生成图表和现象分析。

当面向读者的事实在不同来源中冲突时，展示主报告中的值。不得用次级字段静默改写。若差异影响关键表格，在附录中简洁标注来源或分析范围。

## 主报告选择

优先选择具有清晰标题、模型/分析身份、已陈述指标、结论或结果表的报告。存在多个候选时，优先采用用户指定文件；否则选择其标识符与指标最能对应结构化文件的报告。

不得因模型导出文件更大或更详细而将其误当作主报告。

## 最小证据要求

- 存在主报告或用户明确提供的事实集合时，才生成叙述性报告。
- 存在可用数值时间轴和至少一组数值序列时，才生成图表。
- 表头和行语义可识别时，才生成结果表。
- 关键证据不足时，先说明所需输入，不生成推测性报告。
