# 可视化、指标翻译与报告写作

## 波形识别

通过表头、元数据或单调递增数值识别数值时间列；其余数值列视为候选信号。仅在共享前后缀、元数据、单位或用户上下文支持时，将信号分组。

图例保留原始信号标识符。仅在单位或语义已确认时增加读者友好名称。

## 图表规则

- 时间序列使用折线图，不规则样本使用散点图，离散比较使用柱状图，详细数值使用表格。
- 图表包含标题、坐标轴名称、已知单位、多序列图例、悬停提示和响应式尺寸。
- 同一报告中保持系列与颜色的稳定对应。
- 稠密时间序列提供缩放或范围选择。
- 仅对主报告明确给出或按已记录数据规则可靠识别的事件添加注释。

## 证据化现象说明

按以下逻辑书写：

```text
数据表现 -> 特征提取 -> 有限解释
```

示例：

```text
三条通道在 3.0 s 附近呈现集中的瞬态变化。记录的峰值存在差异，其中通道 X 的数值最大。该波形呈现出各记录通道瞬态响应不完全一致的特征。
```

不得仅根据波形形状推断物理原因。只有主报告、配置或已验证领域证据支持时，才给出物理解释。

## 指标翻译

每个展示指标遵循以下规则：

1. 保留可识别的原始字段或英文缩写。
2. 在含义已确认时添加简洁中文名称。
3. 保留单位和数量级。
4. 统一翻译缺失/状态值：`n/a` -> `暂无数据`；`not assessed` -> `当前结果未形成评价`。
5. 在首个相关表格附近解释一次少见专业指标，不在每行重复解释。

不得猜测未知字段的中文含义。保留原字段名，并在必要时标记为“含义待确认”。

## 论文式中文

- 优先使用“结果表明”“数据呈现”“分析显示”“该指标用于”“本报告采用”。
- 以正向方式描述范围：“本次分析采用……窗口”“该指标作为后续分析项”。
- 避免口语化辩解、生成过程说明和缺少依据的确定性结论。
