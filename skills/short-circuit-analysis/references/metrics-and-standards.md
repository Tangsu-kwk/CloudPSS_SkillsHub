# 短路电流指标与标准

先确认问题关心的是故障点、母线还是设备安装处的电流，以及关注故障初期、开断时刻还是持续期间。不同测点和时间口径对应不同工程用途。

## CloudPSS EMT 结果怎么读

| 结果字段 | 含义与使用条件 |
| --- | --- |
| `peak_current` | 整个分析窗内样点绝对值的最大值。需要判断峰值出现在哪一段时，读 `peak_current_time_s`。 |
| `fault_peak_current` | 仅对故障窗内样点取绝对值最大值。采样频率会影响对连续波形峰值的捕捉。 |
| `fault_rms_current` | 故障窗内样点平方的均值再开方。对含有直流分量的电流波形，该值包含直流分量的贡献。 |
| `steady_fault_rms_current` | 所选子窗口的总 RMS。默认从故障取样窗口两端各裁剪 20%，自定义窗口可覆盖。报告时给出实际窗口，可称为「裁剪窗 RMS」或「指定子窗 RMS」。 |
| `dc_offset_estimate` | 故障窗口内有符号样点的均值。该估计受取窗和非整周期交流分量影响。 |
| `short_circuit_mva` | 当前程序以故障窗总 RMS 和故障母线基准线电压代入三相近似式 `√3 × U(kV) × I(kA)`。解释时说明所用通道、电流口径和三相假设。 |

峰值、RMS 和样点均值统一按实际电流单位换算后解释。报告的全分析窗峰值与故障窗峰值可能来自不同时间段。优先从 `analysis_result.json` 读取所问字段、故障目标、窗口、通道来源和单位依据，再用 `model_parameters.json` 或模型绑定核对测点。只在证据标注相序时才把通道编号解读为 A/B/C。功率/电压换算的等效电流需注明估算方法。由近似短路容量推导的戴维南阻抗、SCR 和 ESCR 沿用同一近似口径。

## 常见交流短路计算量

单相接地、两相相间、两相接地应按不同故障网络处理。对称分量计算时，单相接地涉及正序、负序和零序。两相相间在无接地通路的故障点涉及正序和负序。两相接地还需零序和接地回路。说明故障阻抗、相电流或接地电流的定义以及序阻抗来源。

在故障前平衡、电网以线性序网络等值、故障点相电压为正序等值电源 `E` 的手算条件下，A 相经阻抗 `Zf` 接地时的故障相电流为 `3E / (Z1 + Z2 + Z0 + 3Zf)`。两相金属性相间短路时，每个故障相的电流幅值为 `√3 × |E / (Z1 + Z2)|`。使用同一基准下的复数序阻抗，并明确是交流对称分量估算。精确到标准系数、逆变器贡献或两相接地的实际电流时，按对应故障网络和适用方法取数。

CloudPSS 三相故障电阻的 `ft` 选择切换电阻的相别。A/B/C 是单相选择，AB/AC/BC 是两相选择，ABC 是三相选择。两相选择且电阻公共端接地时，可按接地支路工况解读。对相间故障，需根据实际相间短接拓扑确认回路。报告分别保存配置相别和拓扑端点信息。分量编号继续按结果原名保留，有量测映射证据后再标 A/B/C。单相、两相及单支路事件只给直接电流的幅值和窗口指标，三相近似容量、戴维南等值和 SCR 留空。[CloudPSS 三相故障电阻](https://docs.cloudpss.net/documents/software/emtlab/component-library/basic/electrical/passive-elements/newFaultResistor_3p)

- **初始对称短路电流 I″k**是短路发生初始时刻交流对称分量的有效值。适用于描述故障初期交流电流水平。可采用选定标准的计算方法，或在有明确方法与证据时由波形分离和估计。
- **峰值短路电流 iₚ**关注预期短路电流的最大瞬时值，受交流幅值、直流偏置及衰减等因素影响。用 EMT 采样值比较时，应说明工况、故障合闸角与采样条件。
- **对称开断电流 Iᵦ**关注开断相关时刻的交流对称分量有效值。校核需在设备位置取得适用指标，结合标准定义的时刻、相应直流分量要求和设备额定开断能力。
- **稳态短路电流 Iₖ**描述暂态衰减后的电流水平。利用 EMT 窗口估计时，需要用波形和工况证明已达到对应状态。

给出概念解释或手算示例时，写明假设。例如已知线电压与故障点等值阻抗，可在对称三相金属性短路和指定等值电源电压的假设下用相电压除以每相等值阻抗幅值估算电流。声明使用的电压、阻抗位置和单位。

同一电流通道的峰值和 RMS 都以电流为量纲。对无直流偏置的稳态正弦波，RMS 窗覆盖整周期且采样足够密时，采样峰值与 RMS 之比近似为 √2。比值偏离时，可核对直流偏置、谐波、暂态、采样与取窗。仅凭比值无法判定原因。

裁剪窗 RMS 仍含窗内直流分量。回答标准指标问题时，按所问指标核对规定时刻和计算方法。设备动稳定或短时耐受校核还需设备位置、持续时间与额定值。电流峰值本身不能用于绝缘耐受判定。

## 标准和设备校核

- GB/T 15544.1-2023 是现行三相交流系统短路电流计算标准的电流计算部分。第 2 部分可用于查计算系数，第 3 部分可用于查设备数据，第 5 部分可用于选对照算例。使用第 5 部分算例时，先核对其与所用计算版本的口径。[第 1 部分官方条目](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=D86399BB0989F89A79B6CACBB666DA09) · [系列标准目录](https://openstd.samr.gov.cn/bzgk/gb/std_list?p.p1=0&p.p2=15544)
- 需要引用具体条款、系数或限值时，使用已经取得并核对的适用标准文本，注明版本、条款及适用条件。本参考提供指标口径和官方目录入口。
- 设备校核至少要明确设备及安装位置、故障类型和运行方式、要比较的计算量、开断时刻或耐受持续时间、设备对应的额定值及适用设备标准。缺项时指出缺失的数据，并解释现有结果能支持的判断。现有 EMT 总 RMS、采样峰值和裁剪窗指标各自按表中口径使用。
