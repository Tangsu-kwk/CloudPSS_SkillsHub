# EMT 仿真参数边界

## 当前约定

辅助建模 Skill 只负责为现有 EMT 仿真方案准备输出通道，不负责修改 EMT 的核心仿真参数。

允许的操作范围：

- 创建、修改、删除输出通道；
- 将输出通道登记到现有 EMT 方案的 `output_channels`；
- 使用 EMT 方案默认的采样率、压缩方式等输出属性；
- 用户明确指定时修改新输出组自身的输出属性；
- 保存到新的模型 RID，并在保存后回读验证。

暂不支持修改：

- EMT 仿真步长；
- 仿真总时长；
- 求解器；
- 初始条件；
- 网络或故障计算参数；
- 其他仿真方案；
- 原有输出通道的非必要属性。

## 原因

辅助建模与短路分析职责分离。辅助建模准备模型结构和可观测输出，短路分析 Skill 负责选择分析方案、设置分析参数、启动仿真和解释结果。这样可以避免一次元件编辑意外改变仿真数值设置。

## 后续扩展条件

只有在明确规定参数归属、预览确认方式、保存与回读校验以及与短路分析 Skill 的交接契约后，才考虑开放 EMT 核心参数修改。
